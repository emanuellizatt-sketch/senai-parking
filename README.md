# SENAI Parking

Sistema de gerenciamento de estacionamento desenvolvido para o projeto Mundo SENAI.

## Sobre o projeto

O sistema tem como objetivo facilitar o gerenciamento das vagas de estacionamento, permitindo acompanhar sua disponibilidade e consultar informações relacionadas às vagas.

## Funcionalidades

- Visualização do painel do estacionamento.
- Consulta das vagas disponíveis, ocupadas e agendadas.
- Agendamento de vagas.
- Consulta das vagas do usuário.
- Visualização do mapa do estacionamento.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
